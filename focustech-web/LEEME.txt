FOCUSTECH · TIENDA REAL (versión de producción)  ·  Desarrollado por Onytek
=====================================================================

Esta carpeta es la tienda + panel REAL. Es el mismo diseño aprobado, pero conectada a una base de datos (Supabase):
los productos, pedidos, fotos, vendedores y avisos se guardan de verdad. Funciona como app instalable (PWA).

PASO 1 · Crear el proyecto en Supabase (supabase.com)
  1. New project > nombre "focustech" > elige una contraseña (guárdala) > región "South America (São Paulo)".
  2. Abre SQL Editor > New query > pega TODO el archivo supabase.sql > Run. Debe decir "Success".
  3. Authentication > Sign In / Providers > Email: DESACTIVA "Confirm email" (así los vendedores nuevos pueden entrar al instante).
  4. Project Settings > API: copia "Project URL" y "anon public key".

PASO 2 · Crear las cuentas
  1. Authentication > Users > Add user > Create new user: correo y contraseña de Andrés (marca "Auto Confirm User"). Igual para Fabian.
  2. SQL Editor: en el final de supabase.sql (PASO 2) quita los "--", pon el correo de Andrés y ejecuta. Así Andrés queda como dueño y Fabian como admin.

PASO 3 · Conectar la tienda
  1. Abre config.js, pega la url y la key (la "anon public"; NUNCA la "service_role") y guarda.
  2. Sube la carpeta al repositorio (prototipos-onytek/focustech-web).

PASO 4 · Publicar en Vercel
  1. Vercel > Add New > Project > repositorio prototipos-onytek > Root Directory: focustech-web > Deploy.
  2. Cuando Andrés pase el dominio: Project > Settings > Domains > Add y sigue los 2 registros DNS que te muestre (en Hostinger/Cloudflare, proxy apagado).

PASO 5 · Primer ingreso de Andrés
  Entra a  su-dominio.com/#panel  > Productos > Nuevo producto. Carga fotos, precios y stock.
  En Pagos y envíos: escribe los datos de la cuenta para transferencias (sin eso, la opción Transferencia no aparece al comprar).
  En Integraciones > Redes sociales: usuario de Instagram/TikTok/Facebook y el WhatsApp de ventas (sin eso no aparece el botón de WhatsApp).

AVISOS DE PEDIDOS
  Ya funciona: campana en el panel, etiqueta "Nuevo", contador en la pestaña y aviso del navegador (botón "Activar avisos en este dispositivo" en Integraciones).
  Correo y WhatsApp automáticos: se hacen con n8n. En n8n crea un flujo con nodo "Webhook" (POST), copia su URL y ejecuta en SQL:
     insert into config(k,v) values ('webhook_url','URL-DE-N8N') on conflict (k) do update set v = excluded.v;
  Cada pedido llega a n8n con el pedido completo y el texto listo (campo "msg"): conecta Zoho (correo) y, cuando Meta apruebe el número, WhatsApp Business.
